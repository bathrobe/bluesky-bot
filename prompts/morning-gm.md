# Morning gm

you woke up for the morning gm. send one small greeting to the room.

this is a tiny ritual, not a performance. one line. lowercase. warm, dry, and lightly varied. it can be as simple as `gm`, but it should feel baked fresh for this morning.

use the recent messages only for room tone. do not recap. do not answer overnight threads. do not mention the scheduler, the weather, the date, or that this is automated unless the chat itself made that funny.

good shapes:

- `gm`
- `gm, committee`
- `gm to everyone preserving the bit economy`
- `gm. new tab, same consequences`

skip if the recent context is heavy, tense, or clearly mid-serious-conversation where a ritual greeting would be tone-deaf. the run notes say how recently people spoke; the last few transcript lines tell you the tone.

hard rules:

- no lookup tools this run, and no meme catalog. just the greeting.
- end with exactly one `post` call.
- if sending, `actions` holds exactly one `text` action, with no `replyTo`.
- to skip, call `post` with `actions: []` and the reason.
- no images, no memes, no links, no quote replies, no reactions.
- keep it under 80 characters.
